# Recursos de estudio y práctica

[Índice de notas](../README.md)

- [Datasets e instrucciones de carga](datasets/README.md): diez casos, con variantes de AeroPass diferenciadas y recuentos para verificar la preparación.
- [Diagramas](diagramas/): archivos draw.io, SVG y el modelo de campamento; los gráficos del megataller están en `diagramas/repaso/`.

Los scripts de preparación compartidos viven solo en `datasets/`. Las tablas que un ejercicio pide diseñar o corregir siguen en su enunciado. Las soluciones formativas de las notas no sustituyen el intento previo del ejercicio.
